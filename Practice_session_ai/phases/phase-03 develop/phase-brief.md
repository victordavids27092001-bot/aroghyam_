# Phase 03 — Develop

## Objective

Generate, prototype, test, and refine solutions for the approved Arogyam MVP.

## Primary Questions

- How should users understand and navigate the service?
- What is the shortest safe path to each important outcome?
- How will the experience adapt across devices, abilities, languages, channels, and connectivity?
- How will users understand evidence, professional roles, consent, warnings, status, and recovery?
- Which design performs best in realistic testing?

## Recommended Agents

- Orchestrator
- Interaction design
- UX research
- Healthcare safety
- Accessibility review
- Regulatory and privacy
- Quality assurance

## Relevant Skills

- User flow
- Storyboarding
- Visual design
- Motion design
- Responsive design UI

## Required Deliverables

- Information architecture
- Main and safety-critical user flows
- Storyboards and service scenarios
- Responsive wireframes or prototype
- Visual, content, motion, state, and component specifications
- Consent, error, recovery, emergency, and offline patterns
- Usability and accessibility test findings
- Revised designs and developer acceptance criteria

## Gate

Gate 03 controls movement to Deliver.
