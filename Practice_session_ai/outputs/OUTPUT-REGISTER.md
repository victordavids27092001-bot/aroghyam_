# Arogyam Output Register

## Rules

- Phase output folders contain reviewed deliverables from that phase.
- `approved` contains only human gate-approved artifacts.
- `rejected` preserves failed artifacts and gate reasons.
- `archive` preserves superseded approved versions.
- Never overwrite an approved artifact; create a versioned replacement.
