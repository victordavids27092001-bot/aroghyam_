# Arogyam Input Catalog

## Rules

- Treat files in `Input` as source material.
- Do not overwrite an input during synthesis.
- Record source, owner, date, geography, confidentiality, and verification status.
- Store direct identifiers and sensitive health information only when necessary and authorized.
- Mark drafts, unverified material, promotional sources, and expired documents clearly.

## Input Register

| Input ID | File | Category | Source/owner | Date | Geography | Verification | Sensitivity | Used by |
|---|---|---|---|---|---|---|---|---|

## Categories

- `01-project-brief`: vision, scope, outcomes, terminology
- `02-business-requirements`: BRD, business constraints, service assumptions
- `03-user-research`: consented research data and reports
- `04-secondary-research`: authoritative literature and evidence notes
- `05-domain-expert-interviews`: de-identified expert materials
- `06-regulatory-sources`: original laws, rules, policies, and professional guidelines
- `07-competitor-research`: dated, verified service observations
- `08-design-assets`: approved brand, content, and interface assets
